High1 script mod that will never load

The Sims 4 only loads .ts4script files up to 1 subfolder deep. These are ignored completely - no error, no LastException, they just do nothing. This is the most common result of tidying up a Mods folder.
Evidence: Game script loader depth limit

High1 resource conflict between mods (1 gameplay)

Two or more mods define the same resource ID with different content. The game does not merge these - it loads one and silently ignores the rest, so the other mod's changes never happen. Which one wins is decided by Resource.cfg priority first, then folder depth (shallower wins), then filename order. SimData 545AC67A:00000000:2F1A3C4D5E6F7788 loaded: [MOD] TraitPackB/Bold_Trait_Remake.package (priority 500, depth 2) ignored: [MOD] TraitPackA/Bold_Trait_v1.package
Evidence: Same type:group:instance keys, different payload hashes
✓ Decide which mod you actually want and remove or replace the other. If both are needed, ask the creators for a compatibility patch.
