Four things almost nothing else catches

Existing managers are good at browsing and organising, and trackers tell you whether a mod has been updated. These are the four things that routinely go wrong and are almost never reported.

🕳

Script mods that never load

You tidy your folder, bury a .ts4script two levels deep, and it stops working. No error, no exception, no clue. SimScan flags every script file below the depth the game actually reads.

Evidence: game script-loader depth limit
👥

Duplicates under different names

You re-download a hair and get Hair (1).package. Name-based checkers miss it completely. SimScan compares content hashes, so an identical file is caught whatever it is called.

Evidence: SHA-256 content match
⚔

Conflicts, and who actually wins

Most tools say "these two conflict". None say which one the game applies. SimScan works the winner out from Resource.cfg priority, folder depth and filename order - and names it.

Evidence: same type:group:instance keys, different payload hashes
🧩

Packages that will not parse

One damaged download can make an entire folder look broken. SimScan reads every package index and reports exactly which ones cannot be read, so one bad file does not hide the rest.

Evidence: DBPF header / index parse failure
It also reads the game own crash reports - ranks your installed mods by how likely each one explains the crash, and writes you a 50/50 test plan to narrow it down. The tabs cover findings, load order, every file (with a thumbnail pulled straight out of the package), and the LastException correlation.

What it will not do

This area is full of tools that over-promise. Here is the line, stated plainly.

It cannot prove which mod crashed your game

Nothing can, except the game reproducing the fault. SimScan ranks suspects; you still have to test them.

It cannot run the 50/50 testing for you

It writes the plan and halves the work. It will not launch your game.

It is not antivirus, and not a mod manager

It does not scan for malware and it does not download or update mods. Use a mod manager for that.

Nothing leaves your machine. No account, no telemetry, no internet connection required. Your Mods folder is read locally. Actions are safe by default: Disable moves files into a _disabled folder the game ignores, with Undo to put them back; Delete sends files to the Recycle Bin, not oblivion.
